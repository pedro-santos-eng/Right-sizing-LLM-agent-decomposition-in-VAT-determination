# results/ — Layer-4 sweep artifacts

Layout (grounding `docs/HARNESS_GROUNDING_4_SWEEP.md` §2, §4, §6). Everything
under `results/` is **gitignored except this README** (§8): raw records are large
and are regenerated by the runner; the scored table and analysis tables are
derived data. The artifact of record is the raw records (§6.7).

```
results/
  raw/
    phase<N>/<mode>/<condition>/<case_id>/r<repeat>.json   # one append-only record per run
    phase<N>/ABORTED.json                                   # abort/kill marker
  quarantine/
    phase<N>/<mode>/<condition>/<case_id>/r<repeat>.json    # corrupt records, moved aside
  STOP                                                       # global kill file (create to halt)
  s0prime_knobs/<condition>.json                            # tuned S0' knobs (Phase 2/4; optional)
  scored.csv                                                # score_runs.py output (one row per run)
  analysis/*.csv                                            # analyze.py output tables
```

## Pipeline

1. **Run** (per phase, gated by a DEVLOG-recorded go-ahead):
   `python -m scripts.sweep --phase <N>` — spawns `scripts.run_one` per run in a
   fresh OS process, resumes by skipping complete records, quarantines corrupt
   ones, honours per-phase token/dollar caps and the `results/STOP` kill file.
2. **Score** (offline): `python -m scripts.score_runs` — reads `raw/**`, scores
   against the oracle, writes `results/scored.csv`.
3. **Analyze** (offline): `python -m scripts.analyze` — reads `scored.csv`,
   writes `results/analysis/*.csv` (bootstrap CIs, permutation p-values, d_z,
   Holm, §6.4 cell metrics, §6.6 falsification table).

Steps 2-3 require the optional `analysis` dependency group
(`pip install -e ".[analysis]"`). The runner and `run_one` are stdlib-only.

Phase 0 is the dry run (L2 §11) and never enters reported results.
